# BMGJ Groupe

Site vitrine de l'agence digitale BMGJ Groupe, dédiée aux PME et entrepreneurs du Bénin.

## Présentation

Ce projet est un site vitrine statique développé en HTML, CSS et JavaScript, avec TailwindCSS pour le design.

Il met en avant :
- les services proposés,
- les réalisations,
- l'équipe,
- l'histoire de l'agence,
- les coordonnées et le formulaire de contact.

## Technologies utilisées

- HTML5
- CSS3
- JavaScript
- TailwindCSS

## Lancer le projet localement

Vous pouvez ouvrir directement les fichiers HTML dans le navigateur, ou démarrer un petit serveur local :

```bash
cd /home/quevine/Projets/BMGJ\ Groupe/BMGJ_Site_vitrine
python3 -m http.server 8000
```

Ensuite ouvrez :

```bash
http://localhost:8000
```

## Personnalisation

- Modifier les textes dans les fichiers HTML.
- Changer les couleurs dans `tailwind.config.js` ou dans les classes Tailwind.
- Ajuster les images et logos dans `assets/images/`.
- Mettre à jour les coordonnées et le numéro WhatsApp dans les pages concernées.
